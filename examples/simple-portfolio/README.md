# Example Static Sites

This directory contains example static sites you can use as starting points.

## Simple Portfolio

A clean, responsive portfolio template perfect for developers and designers.

**To use:**
1. Copy files from `examples/simple-portfolio/` to your repository root
2. Replace placeholder content with your own information
3. Commit and push to deploy

**Features:**
- Responsive design
- Fixed navigation
- Project showcase grid
- Contact section
- Modern CSS with gradients

## Adding Your Own Examples

Feel free to contribute additional example templates:
- Landing pages
- Documentation sites
- Business websites
- Creative portfolios
- Blog layouts

Each example should be self-contained and ready to deploy.
